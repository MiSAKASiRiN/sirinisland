# SirinIsland

一个用 Swift、AppKit 和 SwiftUI 写的小型 macOS 菜单栏应用。把鼠标移到屏幕顶部的刘海上，支持触感反馈的触控板会轻震一次，面板随后展开。移入下方歌词区不会触发震动。底栏菜单中的图钉可以固定面板，菜单栏里的SirinIsland图标可以打开功能、隐藏面板或退出。

## 正在播放

播放器将曲目信息发布到 macOS 的「正在播放」后，SirinIsland会在刘海左侧常驻显示封面、曲名、艺人和专辑，在右侧显示实时频谱。横轴从左侧低频到右侧高频，按对数频率排列。收起时归并为 6 个频段，展开后显示 32 个频段。柱高表示对应频段的强度，所有频段共用自动缩放的峰值参考，切换响度不同的曲目后会重新适应。收起和展开时，超出宽度的曲名和艺人／专辑会各自向左循环滚动，两轮之间留有空白并在开头停留 1 秒。切歌时音乐卡片自动展开，展开到位后播放封面切换，默认停留 4 秒；鼠标进入后由悬停接管，移开时收起，固定后保持展开。悬停可查看播放进度，点击播放按钮可暂停或继续。播放与暂停切换时，刘海宽度带阻尼弹簧过渡，封面、曲名和频谱随之与待机图标交叉淡化。暂停时刘海恢复普通外观，仍可从「音乐」页查看曲目。播放器没有提供封面时显示音符。

从菜单栏打开「设置…」，在左侧选择「通用」「专注」「暂存」「音乐」或「关于」。在「专注」可调整计时时长，在「暂存」可管理文件引用。在「音乐」可选择歌词渲染器，调整「收起时显示歌词」和「切歌时自动展开」，以及展开后的停留时间（1–30 秒）。「音乐 → 歌词过滤 → 管理规则…」可分别关闭默认启用的词曲署名、翻译来源和纯音乐提示过滤，也可添加自定义正则表达式。修改立即应用于当前歌词。设置会自动保存。「收起时显示歌词」默认关闭，也可从菜单栏快速切换。开启后，播放有同步歌词的歌曲时，本体下方会保留歌词。鼠标移入歌词范围时歌词收起，点击可直接落到下方窗口；移出后恢复，悬停在顶部本体可展开完整面板。

曲目信息使用 Sirin AL Player 项目中的 MediaRemoteAdapter。实时频谱需要 macOS 14.2 或更新版本和系统音频录制权限。首次播放时请按 macOS 提示授权。若频谱持续没有信号，可在「系统设置 → 隐私与安全性 → 屏幕与系统音频录制」检查SirinIsland的授权，再通过菜单栏选择「重新连接音频频谱」。频谱只读取当前播放器及其匹配的音频辅助进程，音频样本在内存中计算后丢弃。

频谱颜色取自当前专辑封面，切歌时渐变约 0.65 秒。底栏使用 Sirin AL Player 同款 AMLL DOM 歌词引擎。当前句及上下相邻句在同一个视图中排版，由底栏裁切出可见区域。逐字遮罩、长音弹跳与辉光、换行弹簧以及长间隔的三点呼吸动画均由引擎驱动。原文与译文分别按各自宽度横向滚动。原文跟随演唱进度，译文按该句时长滚动，句尾短暂停留。没有译文的句子上下居中。歌名、艺人／专辑与歌词的滚动都采用贝塞尔缓启动和阻尼弹簧减速。底栏右侧的按钮在歌词和「专注 / 暂存 / 音乐」菜单之间切换。

应用优先读取 Sirin AL Player 的本机 LRCX 歌词缓存。缺少逐字时间戳时，应用会按当前曲目信息查询网易云音乐，并尝试从 AMLL TTML 歌词库取得对应歌曲的逐字时间轴。可用的逐行歌词会先显示；补充时间轴到达后，立即切换到当前播放位置。LRCLIB 提供同步歌词后备来源。

## 音量与屏幕亮度

按音量键、屏幕亮度键或使用控制中心调节时，歌词栏会淡入对应的图标、进度条和百分比，静音时显示「静音」。进度条通过阻尼弹簧跟随连续调节。最后一次调节约 1.8 秒后恢复当前歌词。有同步歌词但关闭了常驻歌词时，提示条只在调节期间出现。面板收起时，即使正在播放的歌曲没有歌词或歌词仍在加载，音量和亮度也只从原宽度的底边下拉提示条。鼠标移入本体仍可展开完整面板。

首次使用时，在「系统设置 → 隐私与安全性 → 辅助功能」允许 SirinIsland，或从 SirinIsland 的「设置… → 通用 → 系统提示」打开授权。授权后应用直接处理可调输出设备的音量键和 macOS 原生可调屏幕的亮度键，右上角不再重复显示键盘音量提示。隐藏或退出灵动岛后系统照常处理音量和亮度键。

## 通知与系统专注状态

开启辅助功能权限后，SirinIsland 会把新出现的系统通知横幅显示在歌词位置。应用图标、标题和可见的预览停留约 4 秒，随后恢复原来的内容。在提供专注模式切换横幅的系统上，SirinIsland 会通过相同的辅助功能权限读取横幅上显示的模式名称和开关状态，在同一位置提示约 2.5 秒。

## 电量提示

Mac 接入电源、开始充电或电量降到 20% 及以下时，歌词位置会短暂显示提示。新连接的蓝牙或 USB 外设会显示设备名、连接方式和可用电量；系统提供分部件电量的 AirPods 会分别显示左耳、右耳和充电盒。单个部件开始充电或进入低电量时只提示该部件。设备图标外的圆环按实际百分比顺时针填充，21% 及以上为绿色，11%–20% 为琥珀色，10% 及以下为红色。低电量提醒在回升到 23% 后重新启用。单条电量或连接提示停留约 1.8 秒。多条通知、电量或连接提示连续到达时，按收到顺序每条展示 1 秒。音量、亮度与专注状态可以立即覆盖，随后继续展示被打断的提示及队列，最终恢复歌词。面板收起时提示沿底边下拉。

## 专注

选择 5、25 或 45 分钟，按播放键开始。计时过程中可以暂停、继续或重置。运行中的倒计时按结束时间计算，睡眠和重新启动应用后都会重新核对时间。倒计时结束时，正在运行的应用会播放提示音。

## 文件暂存

把 Finder 中的文件或文件夹拖到刘海，等暂存架展开后松开。拖住暂存列表中的文件名或图标，可将原文件交给支持文件拖放的应用。也可以点复制按钮，在 Finder 的目标文件夹按 ⌘V 粘贴。放大镜会在 Finder 中定位文件，叉号会移除暂存记录。暂存架保存在本机，使用文件书签指向原件。

## 本机编译

需要 macOS 13 或更高版本，以及带 Swift 6.2 或更高版本的完整 Xcode。脚本编译当前 Mac 架构的程序，默认使用 Sirin AL Player 的 Developer ID Application 证书签署框架和主程序。保持同一团队、证书类型和应用标识符，可让后续版本匹配同一项辅助功能授权。其他开发者可用 SIRIN_SIGNING_IDENTITY 指定自己的签名身份。

```sh
./build.sh
open "build/SirinIsland.app"
```

播放器适配器及其依赖随源码放在 Vendor 中，应用包的 Resources/Licenses 包含对应许可。

也可给脚本传入输出目录。刘海屏根据系统提供的安全区域定位，没有刘海时使用主屏幕顶部中央。

歌词引擎的打包文件位于 WebLyrics/assets，普通构建直接使用这些文件。要从已安装依赖的 Sirin AL Player 源码重新生成，运行 `WebLyrics/rebuild.sh /path/to/applemusic-like-lyrics`。源码映射随项目提供，AMLL 和所用依赖的许可证位于 WebLyrics/licenses。

SirinIsland 在自己的 WebLyrics 构建中用 single-line-balancer.ts 替换桌面播放器的断行模块。长句随进度横向滚动；重新打包只读取传入的 AL Player 源码目录。
